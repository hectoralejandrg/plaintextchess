# Chess piece artwork

The chess piece images shipped in the apps are the **cburnett** set by
[Colin M.L. Burnett](https://commons.wikimedia.org/wiki/User:Cburnett),
distributed under the
[Creative Commons Attribution-ShareAlike 3.0 Unported license](https://creativecommons.org/licenses/by-sa/3.0/)
(CC BY-SA 3.0).

- Source SVGs: <https://github.com/lichess-org/lila/tree/master/public/piece/cburnett>
- iOS: `ios/app/PlainTextChess/Assets.xcassets/{w,b}{K,Q,R,B,N,P}.imageset/` (SVG, vector)
- Android: `android/app/src/main/res/drawable-nodpi/{w,b}{k,q,r,b,n,p}.png`
  (rasterized from the same artwork via Wikimedia Commons; transparent background)

This artwork is licensed separately from the rest of the repository (MIT);
the CC BY-SA 3.0 terms apply to the piece images and their derivatives.
